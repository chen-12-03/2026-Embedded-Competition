# STM32F407VET6 上位机控制接口说明

## 1. 通信接口

设备通过 USART1 与上位机通信。

### 串口参数

| 参数 | 配置 |
|---|---|
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |
| 流控 | 无 |
| 电平 | 3.3V TTL |
| 指令结束符 | CRLF，即 `\r\n` |

### 接线

| USB-TTL | STM32F407VET6 |
|---|---|
| TXD | PA10 / USART1_RX |
| RXD | PA9 / USART1_TX |
| GND | GND |

TXD 与 RXD 必须交叉连接，USB-TTL 与开发板必须共地。不得直接连接传统 RS-232 正负电压接口。

## 2. 数据格式

上位机发送 ASCII 文本指令，每条指令必须以 `\r\n` 结束。

示例：

```text
SERVO 90\r\n
```

串口助手中应开启“发送新行”“追加回车换行”或“CRLF”。

指令不区分大小写：

```text
SERVO 90
servo 90
Servo 90
```

以上指令效果相同。

设备处理完每条指令后返回以 `\r\n` 结束的文本结果：

- `OK`：执行成功
- `ERR`：指令或参数错误

建议上位机发送一条指令后等待设备响应，再发送下一条指令。

## 3. 硬件输出接口

| 功能 | MCU 引脚 | 说明 |
|---|---|---|
| SG90 舵机 PWM | PA6 / TIM3_CH1 | 50Hz 舵机控制信号 |
| 步进电机 STEP | PB6 / TIM4_CH1 | 可调频率脉冲输出 |
| 电机 ENABLE | PB7 | 步进驱动器使能输出 |
| 串口发送 | PA9 / USART1_TX | 连接上位机接收 |
| 串口接收 | PA10 / USART1_RX | 连接上位机发送 |

当前接口不包含电机方向控制。步进驱动器的 DIR 引脚需要固定到所需方向电平。

## 4. 控制指令

### 4.1 设置舵机角度

```text
SERVO <角度>
```

参数范围：`0～180` 度。

示例：

```text
SERVO 90
```

成功响应：

```text
OK SERVO=90
```

参数错误响应：

```text
ERR SERVO range is 0..180
```

也支持等号格式：

```text
SERVO=90
```

### 4.2 设置步进电机脉冲频率

```text
STEP <频率>
```

单位：Hz。

参数范围：

- `0`：停止脉冲输出
- `1～20000`：输出对应频率的 STEP 脉冲

输出占空比约为 50%。

示例：

```text
STEP 1000
```

成功响应：

```text
OK STEP=1000
```

停止脉冲：

```text
STEP 0
```

响应：

```text
OK STEP=0
```

参数错误响应：

```text
ERR STEP range is 0..20000 Hz
```

也支持等号格式：

```text
STEP=1000
```

### 4.3 设置电机驱动器使能

```text
ENABLE <状态>
```

| 参数 | 含义 |
|---|---|
| `0` | 禁止电机驱动器 |
| `1` | 使能电机驱动器 |

示例：

```text
ENABLE 1
```

成功响应：

```text
OK ENABLE=1
```

关闭使能：

```text
ENABLE 0
```

成功响应：

```text
OK ENABLE=0
```

参数错误响应：

```text
ERR ENABLE must be 0 or 1
```

命令中的 `1` 始终表示逻辑上的“使能”，上位机不需要考虑 PB7 的实际有效电平。

### 4.4 同时设置全部输出

```text
SET <舵机角度> <步进频率> <使能状态>
```

示例：

```text
SET 45 800 1
```

含义：

- 舵机转到 45°
- STEP 输出 800Hz
- 使能电机驱动器

成功响应：

```text
OK STATUS SERVO=45 STEP=800 ENABLE=1
```

参数范围：

- 舵机角度：`0～180`
- 步进频率：`0～20000Hz`
- 使能状态：`0` 或 `1`

错误响应：

```text
ERR SET <0..180> <0..20000> <0|1>
```

### 4.5 紧急停止步进电机

```text
STOP
```

执行效果：

- 停止 STEP 脉冲
- 关闭电机驱动器使能
- 舵机保持当前角度

成功响应：

```text
OK STOP
```

### 4.6 查询当前状态

```text
STATUS
```

返回示例：

```text
OK STATUS SERVO=90 STEP=1000 ENABLE=1
```

| 字段 | 含义 |
|---|---|
| `SERVO` | 当前舵机目标角度 |
| `STEP` | 当前步进脉冲频率，单位 Hz |
| `ENABLE` | 当前电机使能状态 |

也可以发送：

```text
?
```

### 4.7 查询帮助

```text
HELP
```

设备返回支持的指令列表。

## 5. 上电默认状态

开发板启动后的默认状态：

```text
SERVO=90
STEP=0
ENABLE=0
```

即舵机目标角度为 90°、步进脉冲停止、电机驱动器关闭。

## 6. 推荐控制流程

上位机连接设备后建议按照以下顺序操作：

```text
STATUS
SERVO 90
STEP 500
ENABLE 1
```

停止电机时发送：

```text
STOP
```

如需一次完成设置：

```text
SET 90 500 1
```

## 7. 步进电机转速换算

STEP 频率与电机转速的换算公式：

```text
STEP频率 = 转速RPM × 电机每转整步数 × 驱动器细分数 ÷ 60
```

例如，电机为 200 步/转、驱动器采用 16 细分、目标转速为 60 RPM：

```text
60 × 200 × 16 ÷ 60 = 3200Hz
```

发送：

```text
STEP 3200
ENABLE 1
```

实际转速还会受到负载、驱动电压以及加减速过程影响。较高频率不建议直接跳变，应由上位机逐步提高频率。

## 8. Python 上位机示例

安装串口库：

```bash
pip install pyserial
```

示例程序：

```python
import serial
import time

ser = serial.Serial(
    port="COM3",
    baudrate=115200,
    bytesize=8,
    parity="N",
    stopbits=1,
    timeout=1
)

def send_command(command):
    ser.write((command + "\r\n").encode("ascii"))
    response = ser.readline().decode("ascii", errors="ignore").strip()
    print("TX:", command)
    print("RX:", response)
    return response

time.sleep(1)

send_command("STATUS")
send_command("SERVO 90")
send_command("STEP 1000")
send_command("ENABLE 1")

time.sleep(5)

send_command("STOP")
ser.close()
```

将 `COM3` 修改为设备管理器中显示的实际串口号。

## 9. 异常响应与排查

未知指令：

```text
ERR unknown command; send HELP
```

遇到错误时应检查：

1. 指令是否以 `\r\n` 结束。
2. 参数是否在允许范围内。
3. 串口是否设置为 115200、8N1。
4. TXD 与 RXD 是否交叉连接。
5. USB-TTL 与开发板是否共地。
6. 是否使用 3.3V TTL 串口电平。
